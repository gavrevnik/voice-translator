# Voice Translator

Двусторонний голосовой переводчик с веб-клиентом и нативным Android-приложением. Пользователь выбирает пару языков и нажимает микрофон на стороне языка, на котором говорит; приложение распознаёт речь, переводит текст в противоположную сторону и автоматически озвучивает результат.

Поддерживаются сербский, хорватский, английский, румынский, русский и испанский языки.

## Схема и доступные движки

Каждый голосовой запрос проходит три этапа: `STT → Translate → TTS`.

Android всегда работает в Conversation mode и делит экран на две равные половины: верхняя развёрнута на 180° для собеседника напротив, нижняя ориентирована обычно. У каждого участника есть цветная кнопка речи со встроенным переключателем языка и открываемая на весь экран текстовая карточка. В центре равномерно расположены настройки, **Live** и перестановка сторон. Live непрерывно слушает через Gemini 3.5 Transcribe Live, переводит через выбранный Gemini Flash, озвучивает результат и после воспроизведения начинает следующий цикл; пока Live активен, приложение не даёт экрану погаснуть по системному тайм-ауту. Во время прослушивания кнопка перестановки сторон заменяется кнопкой перевода: она завершает текущую запись и переводит реплику, тогда как повторное нажатие **Live** отменяет весь режим без перевода.

Диагностический экспорт Live сохраняет только последнюю сессию между включением и выключением режима с отдельными пронумерованными циклами. Для разбора неверного направления перевода Live-лог включает промежуточный и итоговый распознанный текст, признаки и результат классификации, параметры маршрутизации, перевод и фактически выбранный TTS-голос; аудио и API-ключи не записываются. Новое включение Live перезаписывает предыдущую сессию.

| Этап | Web | Android |
| --- | --- | --- |
| **STT** — речь → текст | **Browser STT** (`SpeechRecognition`) по умолчанию или **Groq Whisper Large V3** (`whisper-large-v3`) | Только потоковый **Gemini 3.5 Transcribe Live** (`gemini-3.5-transcribe-live`) |
| **Translate** — перевод | **Gemini Flash 3.1** по умолчанию (`gemini-3.1-flash-lite`, thinking `minimal`), **Gemini Flash 3.5** (`gemini-3.5-flash-lite`) или **Codex SDK** (`gpt-5.6-luna`, reasoning `low`) | **Gemini Flash 3.5** по умолчанию (`gemini-3.5-flash-lite`, thinking `minimal`) или **Gemini Flash 3.1** (`gemini-3.1-flash-lite`); GPT/OpenAI и offline translation в мобильной сборке не используются |
| **TTS** — текст → речь | **Browser TTS** по умолчанию или **Gemini 3.1 Flash TTS Preview** (`gemini-3.1-flash-tts-preview`) | Только **Android System TTS** |

Выбор модели перевода действует до перезапуска: при обновлении веб-страницы снова выбирается Gemini Flash 3.1, а при новом запуске Android-приложения — Gemini Flash 3.5. Остальные пользовательские настройки сохраняются.

На вебе распознавание по умолчанию выполняет встроенный браузерный `SpeechRecognition`. Если в настройках выбран Groq Whisper, WAV-запись отправляется с локального Node-бэкенда в Groq. Gemini TTS возвращается браузеру как WAV. Ключи Gemini и Groq не передаются браузерному JavaScript. Android читает и встраивает только `GEMINI_API_KEY`; отдельный блок конфигурации API-ключа в мобильном интерфейсе скрыт.

Для Android TTS проверяются локальные голоса обоих выбранных языков. При отсутствии системного сербского голоса предлагается Piper ONNX Android TTS Engine с моделью `sr_RS-serbski_institut-medium`. Универсальной тихой загрузки TTS в Android нет, поэтому Install открывает установщик конкретного движка или системные настройки.

Gemini Transcribe Live использует server VAD с паузой 700 мс, высокой чувствительностью окончания речи и 250 мс prefix padding; локальный RMS с паузой 1 секунда служит страховкой. PCM передаётся потоково, завершение выполняется через `audioStreamEnd`.

Исходники и runtime прежних Whisper/OPUS/Groq/Android STT реализаций сохранены в `android/optional/`, но не подключены к Gradle и не попадают в APK. `material-icons-extended` также удалён: необходимые расширенные glyphs определены локально в `AppIcons.kt`.

## Быстрый запуск веб-версии

Нужны Node.js 20+ и заполненный `GEMINI_API_KEY` в корневом `.env` для выбранного по умолчанию Gemini Flash 3.1. `GROQ_API_KEY` нужен только при выборе Groq Whisper, а локальная авторизация Codex — только при выборе Codex SDK.

Самый простой способ на macOS — дважды нажать [`Say it.app`](Say%20it.app). Нативный ярлык работает без окна Terminal: при необходимости установит npm-зависимости, в фоне запустит Node API и Vite, затем откроет [http://voice-translator.localhost](http://voice-translator.localhost) через установленный в `life-hub` Caddy. Внутренний адрес — `http://127.0.0.1:5173`. Локальные логи и PID хранятся в игнорируемой папке `.runtime/`.

При запуске через Life Hub вкладка отправляет локальный heartbeat. После закрытия всех вкладок Life Hub может остановить веб-версию по PID согласно политике `stopWhenBrowserIdle`; Android-приложение этим механизмом не управляется.

Ручной запуск:

```bash
npm install
cp .env.example .env  # только если .env ещё не создан
npm run dev
```

Gemini Flash 3.1 выбран по умолчанию; в настройках можно переключиться на Flash 3.5 или Codex SDK. Настройки Codex можно переопределить переменными из [`.env.example`](.env.example).

## Конфигурация и секреты

Единственный локальный файл секретов — `.env`; он исключён из Git. Репозиторий содержит только безопасный шаблон [`.env.example`](.env.example):

- `GROQ_API_KEY` — опциональный Groq STT только на вебе;
- `GEMINI_API_KEY` — Gemini-перевод в вебе/Android, Gemini 3.5 Transcribe Live на Android и Gemini TTS в вебе;
- `CODEX_CLI_PATH` — необязательный путь к Codex CLI для веб-провайдера;
- `PORT` — порт локального API, по умолчанию `8787`.

Android-сборка читает только Gemini-ключ из корневого `.env` и встраивает его в APK. Такой APK предназначен только для личного тестирования: ключ можно извлечь. Перед распространением приложения перенесите облачные вызовы на собственный backend и отзовите встроенный ключ.

## Android

Подробности находятся в [`android/README.md`](android/README.md). Для сборки нужны JDK 17 и Android SDK 35:

```bash
cd android
env JAVA_HOME=/opt/homebrew/opt/openjdk@17/libexec/openjdk.jdk/Contents/Home \
  ./gradlew testDebugUnitTest lintDebug assembleRelease
```

Release APK создаётся в `android/app/build/outputs/apk/release/`. APK/AAB, `.env`, `references/`, зависимости, модели и build-каталоги исключены из Git.

## Команды

```bash
npm run dev           # Node API + Vite в режиме разработки
npm run check         # unit-тесты, TypeScript и production build
npm run start         # production-сервер на 127.0.0.1:8787
```

## Структура проекта

- `src/` — React-интерфейс, Browser STT/TTS, запись звука для Groq и клиент API.
- `server/stt/` — серверный адаптер Groq Whisper.
- `server/translation/` — изолированные провайдеры Codex SDK и Gemini.
- `server/tts/` — серверный адаптер Gemini TTS для веб-клиента.
- `android/app/` — активное Jetpack Compose приложение.
- `android/tools/` — сохранённые инструменты FP32-конвертации OPUS, квантизации Whisper и сборки JNI runtime.
- `android/optional/` — отключённые Android providers, manifests, AARs, лицензии и исходный модуль `whisper.cpp`; эти каталоги не входят в активную сборку.

Веб и Android используют одну и ту же системную инструкцию с каноническими именами и кодами выбранных языков. Веб-адаптер Codex передаёт её как `developer_instructions`, а Gemini в вебе и Android — как `systemInstruction`; распознанный текст всегда отправляется отдельно как недоверенный user input. Ответ переводчика проверяется по минимальной JSON-схеме. Замеры этапов доступны как `[timing]` в веб-консоли/Node и через Android-тег `SayItTiming`.
