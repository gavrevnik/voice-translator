# Say it — Android

Нативный Jetpack Compose клиент для двустороннего голосового перевода на Android 8+ (`minSdk 26`). Поддерживаются сербский, хорватский, английский, румынский, русский и испанский языки. Офлайн-перевод требует arm64 и Android 9+ (API 28).

## Движки

- Распознавание: **Groq Whisper Large V3** по умолчанию, а также ручные **Android/Samsung SpeechRecognizer** и локальный пакетный **Whisper Offline** с единственной multilingual-моделью `large-v3-turbo-q4_0`.
- Перевод: **Gemini Flash 3.5** (`gemini-3.5-flash-lite`) по умолчанию; также доступна Gemini Flash 3.1 (`gemini-3.1-flash-lite`), обе используют thinking `minimal`. Единственная офлайн-альтернатива — полноточный **OPUS Slavic FP32 — Offline** для `Russian ↔ Serbian/Croatian`. OpenAI/GPT в Android-клиенте не используется.
- Озвучивание: только **Android System TTS**.

Gemini translation использует `GEMINI_API_KEY`, а Groq STT — `GROQ_API_KEY`; оба значения читаются из корневого `.env` во время сборки. Конфигурация API-ключей в интерфейсе приложения временно скрыта.

Офлайн OPUS отвечает только за перевод. Для полностью автономной цепочки можно выбрать Whisper Offline вместо системного STT; Android TTS всё равно требует установленный локальный голос целевого языка. Приложение выбирает только TTS-голос, не требующий сети, и выводит отдельные понятные ошибки для отсутствующего голоса, неподдерживаемого системного языка распознавания (`error 12`) и нескачанной системной модели распознавания (`error 13`).

При ручном выборе распознавания **Android** приложение проверяет offline-пакеты для обоих выбранных языков среди служб Samsung и Google. Если пакет найден, фактическое распознавание привязывается к проверенной службе, а шкала остаётся в обычном виде. Отсутствующий, но доступный пакет можно запросить прямо по ссылке под шкалой (`triggerModelDownload` на Android 13+); если служба не поддерживает прямую загрузку, открываются системные настройки голосового ввода. Для режимов Groq и Whisper эти STT-ссылки не показываются.

Android TTS аналогично проверяет offline-голоса обоих выбранных языков в порядке Samsung → Google и использует именно проверенный движок и локальный голос. Установленный голос не меняет внешний вид шкалы. Android не предоставляет общего API для фоновой установки конкретного TTS-языка, поэтому при отсутствии голоса ссылка **Install** открывает установщик голосовых данных выбранного движка (либо системные настройки TTS); после возврата приложение повторяет проверку.

Главный экран рассчитан на узкие телефоны: сверху расположена компактная однострочная шкала движков, а справа от неё — кнопки Conversation mode и настроек. В Single mode под ними два селектора языков занимают всю ширину строки. Кнопки речи сохраняют ширину в половину экрана, но увеличены по высоте для удобного нажатия. Исходная фраза и перевод идут полноширинными карточками друг под другом, растут по содержимому и прокручиваются вместе с экраном; пустые карточки не показывают placeholder. Нажатие на любую заполненную карточку открывает текст на весь экран, а перевод можно скопировать отдельной кнопкой. Шкала показывает короткие имена реально выбранных движков, по умолчанию `Groq Whisper → Gemini 3.5 → Android`; во время записи в ней виден таймер, а во время озвучивания — квадратная кнопка остановки. Галочки наличия языковых пакетов в шкале не отображаются.

Conversation mode формирует две равные половины экрана для беседы лицом к лицу. Верхняя половина целиком повёрнута на 180° и читается человеком напротив, нижняя ориентирована обычно; системные отступы выравниваются по большему значению, поэтому расстояния от внешних кнопок до краёв симметричны. В каждой половине есть текстовая карточка и компактная цветная кнопка речи высотой 56 dp; справа в эту же кнопку встроена секция с кодом языка и выпадающим списком. Текст сначала автоматически уменьшается с 25 до 12.5 sp, а затем переходит в прокрутку. У карточки актуального перевода есть кнопка Replay, которая во время озвучивания заменяется кнопкой Stop; нажатие на саму заполненную карточку открывает её на весь экран в ориентации соответствующего собеседника. Центральная линия не содержит progress bar: уменьшенные Settings, выход из Conversation mode и перестановка сторон равномерно распределены по всей её ширине. Режим сохраняется между запусками и также выбирается через фильтр **Layout → Single mode / Conversation mode** в настройках.

Настройки открываются отдельным прокручиваемым экраном. Блоки следуют порядку: **Recognition**, **Translation**, **Playback**, **Android speech packages**, **Automatic stop**, **Layout**, затем **Diagnostics**. В Recognition доступны Groq Whisper, Android Speech и Whisper Offline; автоматический выбор движка не используется. В Layout выбирается Single mode или Conversation mode. В Playback показан отдельный выпадающий список с единственным текущим вариантом **Android Speech**. В Android speech packages переключатель STT/TTS перечисляет доступные Samsung/Google STT и Samsung/Google/Piper ONNX TTS для всех шести языков: скачанные отмечены галочкой, для отсутствующих доступна кнопка загрузки. Если системного офлайн-голоса для сербского нет, TTS-список предлагает официальный sherpa-onnx Android TTS Engine APK со встроенной Piper-моделью `sr_RS-serbski_institut-medium`; ссылка выбирается по ABI телефона. После установки приложение подключается к движку напрямую, поэтому делать его системным TTS по умолчанию не требуется. Если Android ещё не зарегистрировал сервис, кнопка **Initialize** открывает движок, после чего список можно обновить. Прямое скачивание STT работает через `SpeechRecognizer` на Android 13+, а остальные системные TTS открывают установщик голосов провайдера, поскольку универсального API для тихой установки конкретного языка нет. В Automatic stop задаётся пауза для Groq Whisper от 0,1 до 5,0 секунды с точностью до одной десятой; значение по умолчанию — 2 секунды. При auto-stop перед отправкой в Groq служебная тишина обрезается до 300 мс post-roll. Блок API keys из интерфейса убран. Кнопка **Export logs** открывает системное меню «Поделиться» для диагностического файла последнего речевого цикла, включая незавершившийся ошибкой цикл. В файл входят конфигурация движков, безопасные сведения об устройстве, этапы, тайминги и технические ошибки; для Groq Whisper дополнительно записываются безопасные метаданные `verbose_json` по сегментам и объём обрезанной тишины, а для локального Whisper — внутренние времена mel/sample/encode/decode/prompt, количество проходов и fallback-счётчики. Аудио, распознанный и переведённый текст, а также API-ключи не записываются. Системная инструкция перевода совпадает с веб-версией, содержит канонические имена и коды языков, а transcript отправляется отдельным user input.

## Whisper Offline

Локальное распознавание использует одну multilingual-модель Whisper, доступную для всех шести языков приложения и не зависящую от языковых пакетов Samsung/Google. Нативный CPU-only arm64 runtime входит в APK, а веса скачиваются отдельно в настройках:

- **Large V3 Turbo Q4_0**: `473 992 235` байт (474,0 MB), SHA-256 `2ceb779ca61ce46ed6e9aa43c4a0f8a89a37f683df3c0ba3119238fcd5852155`.

Delivery manifest находится в `app/src/main/assets/whisper_models.json` и указывает на GitHub Release `offline-whisper-large-v3-turbo-q4_0-v1`. URL можно переопределить через `OFFLINE_WHISPER_MODEL_URL` в корневом `.env`. Квантизация официальной multilingual Large V3 Turbo-модели воспроизводится командой `tools/quantize_whisper_model.sh`. Нативный runtime собран из закреплённого commit `whisper.cpp` и хранится в `app/libs/whisperlib-release.aar` без весов. При обновлении приложения ранее скачанный Small Q5_1 удаляется из app-private storage.

Large V3 Turbo заранее загружается до начала записи и остаётся в памяти между фразами. Распознавание и Silero VAD используют шесть CPU-потоков. Перед финальным decode VAD обрезает только внешнюю тишину, сохраняя внутренние паузы и защитные поля 250 мс до и 350 мс после речи; при отсутствии уверенных границ или экономии менее 500 мс используется исходная запись. Silero VAD v6.2.0 весом 885 098 байт входит в APK. После Stop приложение дописывает 200 мс звука и запускает финальный beam-search по подготовленной полной реплике.

`Whisper Offline` записывает до второго нажатия, затем выполняет один decode всей сохранённой речи с beam-3, отключёнными timestamps и температурными fallback-проходами и выбранным пользователем языком. Его результат передаётся в перевод.

Замеры пишутся с тегом `SayItTiming`: preloading, VAD и факт обрезки, исходная/декодируемая длительность аудио, final decode, Stop-to-final, process CPU time и PSS. Экспорт последнего цикла также содержит нативную разбивку Whisper на mel/sample/encode/decode/prompt, число запусков каждой стадии и количество fallback-проходов. На подключённом телефоне их можно смотреть через `adb logcat -s SayItTiming`.

## OPUS Slavic FP32 — Offline

Android использует полноточный `Helsinki-NLP/opus-mt-sla-sla` через Bergamot/Marian и локально собранный `translate-kit` AAR. Исходная модель знает более широкий набор славянских вариантов (`bel`, `bos_Latn`, `bul`, `ces`, `hrv`, `mkd`, `pol`, `rus`, `slv`, `srp_Latn`, `srp_Cyrl`, `ukr` и другие), но приложение разрешает провайдер только для пар `ru ↔ sr` и `ru ↔ hr`. При другой паре пункт неактивен, а дополнительная проверка в ViewModel и provider не позволяет обойти ограничение.

Для направления RU→SR доступны `>>srp_Latn<<` (по умолчанию) и `>>srp_Cyrl<<`; RU→HR использует `>>hrv<<`; для обратных направлений используется `>>rus<<`. В многофразовом тексте приложение сегментирует вход на предложения и добавляет целевой токен к каждому из них: Bergamot токенизирует предложения независимо, поэтому один токен только в начале абзаца повреждал перевод со второго предложения. Автоопределение языка этому provider не требуется. Android Speech и Android TTS используют для хорватского системную локаль `hr-HR`, поэтому их офлайн-работа зависит от установленных Google-пакетов распознавания и голоса.

ModelManager поддерживает состояния `NotInstalled`, `Downloading(progress)`, `Installed`, `Invalid` и `Error`, проверяет SHA-256 архива и каждого runtime-файла, безопасно распаковывает ZIP и хранит модель в `filesDir`, поэтому обычное обновление APK её не удаляет. Веса не входят в APK и Git:

- скачивание: `237 545 582` байта (237,5 MB);
- после установки: `257 555 545` байт (257,6 MB);
- основной FP32-файл: `254 918 431` байт;
- SHA-256 пакета: `eaac8da16c466928fdfc23bd23dc9a296f1f373d2433c19bc7b8006a8b254298`;
- локальный готовый artifact: `offline-opus-sla-fp32-v1.zip` (игнорируется Git).

Delivery manifest находится в `app/src/main/assets/offline_models.json`. Его стандартный URL указывает на GitHub Release `offline-opus-sla-fp32-v1`. Для локального/CDN-теста можно задать `OFFLINE_OPUS_MODEL_URL` в корневом `.env` перед сборкой.

Воспроизводимая конвертация исходного Marian checkpoint в Bergamot FP32 без квантования, сборка совместимых SentencePiece-словарей и shortlist выполняются скриптом:

```bash
python3 tools/build_offline_opus_pack.py \
  --marian-conv /path/to/x86_64/marian-conv \
  --work-dir /tmp/sayit-opus-build \
  --output-dir model-packs \
  --app-manifest app/src/main/assets/offline_models.json
```

Скрипт при отсутствии `--source-dir` сам скачивает закреплённый архив OPUS и проверяет его checksum. JNI AAR без локальных изменений можно пересобрать из закреплённого upstream commit командой `tools/build_translate_kit_aar.sh`; лицензии и notices лежат в `app/libs/`. При обновлении приложения старый каталог `opus-mt-sla-sla-int8`, а также каталоги удалённой Indo-European модели очищаются автоматически.

## Сборка

Создайте корневой `.env` из шаблона и заполните ключи:

```bash
cp ../.env.example ../.env
```

Затем откройте каталог `android` в Android Studio либо используйте JDK 17 и терминал:

```bash
./gradlew testReleaseUnitTest assembleRelease
```

Release APK будет создан в `app/build/outputs/apk/release/`. Build-каталоги, APK и model pack исключены из Git.

> Важно: Gradle встраивает Gemini и Groq ключи в APK. Их можно извлечь, поэтому такую сборку нельзя публиковать или передавать третьим лицам. Для распространяемой версии используйте backend и отзовите тестовые ключи.

## Использование

1. Выберите два языка и нужные движки в настройках.
2. Нажмите микрофон под исходным языком и говорите. В режиме Groq Whisper перевод начнётся автоматически после настроенной паузы; в остальных режимах продолжайте запись до ручной остановки.
3. При необходимости нажмите ту же кнопку ещё раз, чтобы остановить запись вручную: финальный текст будет переведён и озвучен.
4. Кнопка **Stop** останавливает воспроизведение; кнопка play повторяет последний перевод.

System SpeechRecognizer может показывать частичный текст во время записи. Поскольку системный сервис завершает отдельную сессию после паузы или внутреннего лимита, приложение автоматически запускает следующую и объединяет соседние результаты без повторов. На границе возможна короткая пауза. Groq записывает аудио локально и возвращает результат после ручной остановки либо после обнаруженной паузы, а Whisper Offline — после ручной остановки. В APK входит только нативный Whisper runtime; веса Large V3 Turbo размером 474,0 MB загружаются и хранятся отдельно в app-private storage.

Для диагностики задержек используйте:

```bash
adb logcat -s SayItTiming
```
